# V_Txn Client (Fabric 1.21.11)

Drop .mp3 files in `<minecraft folder>/vtxn/music`, press **M** (rebind under Options > Controls > V_Txn Client).

Tabs: Library, Now, Queue, Themes (25 themes: 12 glass + 13 solid). Theme, volume and loop are saved
in `<minecraft folder>/vtxn/config.properties`.

Build: push to GitHub, the Actions workflow produces `vtxn-client-1.0.0.jar` as an artifact.
